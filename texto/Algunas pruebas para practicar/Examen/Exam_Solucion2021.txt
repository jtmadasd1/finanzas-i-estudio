Question II:  
2a) What are the seven basic characteristics that a good measure of risk must have (as discussed 
in class)? 
Answer: 
 
We only discussed 5 characteristics (not seven): 
-It should consider the width of the return distribution 
- It should give more weight to recent data 
- It should consider the asymmetry of the return distribution 
- It should consider the tails of the return distribution (extreme events) 
- It should be easy to explain
