Question II:  
 
2a) If we believe in the risk-return relationship, given that the riskless asset has zero risk, then it 
should have an expected return equal to zero. Please, provide one reason about why the riskless 
asset gives an expected return higher that zero (i.e. rf >0). 
Answer: 
 
One reason is that if you invest an amount X in such riskless asset, you postpone the 
consumption of goods to the future, instead of consuming X today. Since, postponing (i.e. 
waiting) is costly, then rf >0. 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
2b) Financial crises are bad for investments since we expect a decrease in stock prices, which 
cannot be exploited economically. Thus, we have to wait to periods of financial booms, where we 
have expectations about increases in prices. Please, provide an example. 
Answer: 
 
This sentence is wrong. When we expect a decrease in stock prices, we can use short sales to 
exploit economically such price reductions.
